# ⛏️ Minecraft Performance Logs & Analysis

Репозиторий для сбора, анализа и оптимизации производительности моей кастомной сборки Minecraft. Здесь я делюсь логами, отчетами профилирования и результатами тестов, чтобы отслеживать стабильность игры и бороться с лагами (FPS/TPS).

## 🚀 О проекте
Цель этого репозитория — детальный разбор поведения сборки под нагрузкой. Я ищу «тяжелые» моды, оптимизирую конфигурации сервера/клиента и фиксирую изменения производительности после обновлений.

* **Версия Minecraft:** 1.20.1 *(укажите свою)*
* **Ядро / Загрузчик модов:** Forge / Fabric *(укажите свое)*
* **Количество модов:** ~150 модов

## 📂 Структура репозитория
* `/logs` — ежедневные или сессионные логи игры (`latest.log`, `debug.log`).
* `/crash-reports` — отчеты о крашах (если сборка упала) с разбором причин.
* `/profiling` — отчеты из инструментов оптимизации (Spark, Spark-профайлы, Essentials и др.).
* `/configs` — оптимизированные файлы конфигураций модов и Java флагов.

## 📊 Используемые инструменты для анализа
* **[Spark](https://lucko.me)** — основной профайлер для поиска виновников низкого TPS и лагов процессора.
* **[Observable](https://curseforge.com)** — для поиска тяжелых энтити и блоков (Tile Entities) в реальном времени.
* **Java Garbage Collection Logs** — для настройки и мониторинга флагов сборщика мусора (Aikar's Flags / Generational ZGC).

## 📈 Текущие результаты & Находки

* *(Пример)* Заменил «тяжелый» мод на анимации аналогом, FPS вырос на 15%.
