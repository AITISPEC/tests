# Developer Instructions

## Quick Start
- Initialize: `npm init` (or equivalent for your language)
- Install deps: `npm install`
- Lint: `npm run lint`
- Typecheck: `npm run typecheck`
- Format: `npm run format`
- Test: `npm test`
- Build: `npm run build`

## Conventions
- Follow existing code style in the repository
- Run lint → typecheck → test before committing
- Use `.gitignore` patterns as documented

## Notes
- Repository contents may be minimal or empty; check root directory for project files
